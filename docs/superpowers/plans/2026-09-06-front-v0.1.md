# Casal Conectados Front v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a primeira versão visual mobile do Casal Conectados, inspirada na experiência geral do Life360, com mapa dominante, dois perfis simulados, painel inferior e navegação básica, sem login ou backend.

**Architecture:** Aplicação React + TypeScript + Vite, organizada em componentes pequenos. Os dados simulados ficam isolados em `src/data`, enquanto a tela consome esses dados como se viessem de uma API. O mapa usa React Leaflet com tiles do OpenStreetMap e apresenta fallback visual se houver falha de carregamento.

**Tech Stack:** React, TypeScript, Vite, React Leaflet, Leaflet, Lucide React, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-06-front-v0.1-design.md`

## Global Constraints

- A v0.1 é exclusivamente de front-end.
- Não implementar login, cadastro, pareamento real, backend, banco de dados, GPS real, rastreamento em segundo plano, notificações, histórico ou geofencing.
- O mapa deve ser o elemento dominante da interface.
- A experiência deve ser mobile-first e inspirada na estrutura geral do Life360, sem copiar identidade visual, marca, ícones proprietários ou layout pixel a pixel.
- Os dois perfis e posições devem ser totalmente mockados.
- Os mocks devem ficar isolados da UI para permitir substituição futura por dados reais.
- A estrutura deve permanecer preparada para futura evolução para PWA/Capacitor.
